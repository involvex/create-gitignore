# Plan: Append `*.log` to Generated .gitignore Files

The goal is to ensure that every `.gitignore` file generated by the CLI contains the `*.log` pattern at the end of the file, if it is not already present in the template fetched from GitHub.

## Proposed Changes

### `src/index.js`

- Create a helper function `ensureLogPattern(content)` that:
  - Checks if `*.log` is already in the `content`.
  - If not, appends `\n\n# Custom logs\n*.log\n` to the content.
- Update the `getGitignore` callback or `createFile` to process the content using this helper before writing to disk.

## Implementation Steps

1.  **Refactor `createFile`**: Modify `createFile` to accept the processed content or process it internally.
2.  **Add logic to append pattern**:
    - Use a regular expression or simple string search to check for `*.log`.
    - Append the pattern at the end of the string.
3.  **Verify**: Run the CLI with a template (e.g., `node lib/index.js node`) and verify that `*.log` is present in the generated `.gitignore`.

### Automated Tests

- The project currently uses `mocha` for testing (according to `package.json`). I will check for existing tests and add a new test case to verify the `*.log` inclusion.

### Manual Verification
