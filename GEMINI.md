# create-gitignore

`create-gitignore` is a Node.js-based CLI tool that fetches `.gitignore` templates from the official [github/gitignore](https://github.com/github/gitignore) repository and generates them locally.

## Project Overview

- **Purpose:** Provide a quick way to generate standard `.gitignore` files from a terminal.
- **Core Logic:** Fetches templates using the GitHub API/Raw content, prompts for overwrites, and ensures a base level of protection by appending `*.log` if missing.
- **Architecture:**
  - `src/`: Source code using ES2015+ syntax.
  - `lib/`: Compiled output generated by Babel.
  - `test/`: Unit tests for core utilities.

## Main Technologies

- **Runtime:** Node.js
- **Transpiler:** Babel (presets: `es2015`, `stage-2`)
- **Key Libraries:**
  - `axios`: HTTP client for template fetching.
  - `inquirer`: Interactive CLI prompts.
  - `chalk`: Terminal string styling.
  - `minimist`: Argument parsing.
  - `mocha` & `chai`: Testing framework and assertion library.

## Building and Running

### Commands

- **Build:** `npm run compile` - Transpiles `src/` to `lib/`.
- **Run:** `npm start` - Executes the compiled `lib/index.js`.
- **Dev:** `npm run dev` - Watches `src/` and recompiles on changes.
- **Test:** `npm test` - Runs Mocha tests against the code in `lib/`.

### Usage

```bash
# List available templates
create-gitignore list

# Generate a specific .gitignore (Case Sensitive)
create-gitignore Node
```

## Development Conventions

- **Source Control:** Edit files in `src/`, never directly in `lib/`.
- **Compilation:** Always ensure `npm run compile` is run before testing or distribution, as the `bin` and `main` entry points point to `lib/`.
- **Testing:** Tests use `require` on `../lib/index`, so they verify the compiled output.
- **Feature Focus:** The project currently includes a custom `ensureLogPattern` feature that enforces `*.log` inclusion in all generated files.
- **Roadmap:** A noted todo in the README is to remove case sensitivity for template names.
